Find the best layout for your ship

Three steps, all in the settings panel. Everything runs in your browser.

  1. Type your ship's name and press Use this hull. Its ship level decides which rooms you can build.
  2. Pick a weapon setup (e.g. missiles with hangars) and press Recommend rooms, then Use these rooms. You can edit the list afterwards.
  3. Pick a time and press Start search. The best layout appears here and improves while it runs; copy the coordinates to build it in the game.

Room list

Add a room by type

The type decides how a room is placed: priority rooms (reactors, shields) get the most armor, combat rooms are armored and linked for crew travel, non-combat rooms stay away from armor and lifts, resource rooms go on r tiles. Armor on a room is its own sweet spot (e.g. 4-6); empty = the default.

Search details

Leave restarts at 0 and use the time limit (or Stop): the search then runs in rounds on every CPU core and shares the best layouts between cores after each round.

Python runs through Pyodide in a Web Worker. The search uses several CPU cores; the command-line version is still faster for very long runs.
