Ship Layout Optimizer

Searches for room, lift, vent and armor layouts on a hull grid. Runs entirely in your browser.

How to use this page
  1. Hull: type your ship's name under Find a ship hull and press Use this hull. Its ship level is picked up for the room recommendations.
  2. Rooms: press Recommend rooms for a weapon setup (for example missiles with hangars), check the list and press Use these rooms. Edit any room afterwards: type a game room's name and its size and type are filled in.
  3. Search: press Start search. The best layout updates as the search runs; stop whenever you like. Copy the coordinates or download the picture to build it in the game.

The Top 100 analysis page shows what the best players build, and opens their hulls and builds here.

Recommend rooms for a build

Pick a weapon setup. The room list is built from what top-100 ships of that build run, scaled to your hull, and uses only rooms your hull's ship level can build (at the best level it allows).

Replaces your room list and armor count.

Name each room, pick its type and set how many. The type decides how it is placed: priority rooms (reactors, shields) get the most armor, combat rooms are armored and linked for crew travel (anti-air is also pulled to the middle of the other combat rooms), non-combat rooms stay away from armor and lifts, resource rooms go on r tiles. Armor = this room's own sweet spot (e.g. 4-6); leave empty for the default.

More search options

Leave restarts at 0 and use the time limit (or press Stop) to keep searching. The search then runs in rounds on every CPU core and shares the best layouts between cores after each round. Results improve with more time.

Python runs through Pyodide in a Web Worker. The search uses several CPU cores; the command-line version is still faster for very long runs.
